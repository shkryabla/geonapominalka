# напомниТут

## О приложении

**напомниТут** — Android-приложение для напоминаний, привязанных не ко времени, а к месту.
Вместо будильника «напомни в 18:00 зайти на почту» — ставишь метку на карте там, где
почта реально находится, и приложение напомнит само, как только окажешься рядом,
в любое время дня.

Как это работает:
1. Долгим нажатием на карте отмечаешь место, даёшь задаче название и, при желании, описание.
2. Приложение в фоне следит за геопозицией и сравнивает её с координатами активных задач.
3. При входе в заданный радиус — уведомление с кнопками «Выполнено» / «Отложить».

Технически — Kotlin, MVVM + Repository, карта на OSMDroid, foreground-сервис геолокации
с адаптивной экономией батареи, менеджер задач, гибкие настройки.

## Установка

Готовый APK можно скачать без сборки — во вкладке **Releases** репозитория (справа на
главной странице GitHub, или `/releases`), файл `napomniTut-debug.apk` у последнего релиза.
Разрешите установку из неизвестных источников и установите на устройство (Android 7.0+).

## Как открыть и собрать из исходников

1. Откройте папку проекта в Android Studio.
2. Скопируйте `local.properties.example` в `local.properties`, укажите `sdk.dir` и
   `CARTO_API_KEY` — бесплатный ключ CARTO Basemaps (обязателен с 2026 года для карты,
   иначе водяной знак), получить на [carto.com/basemaps/apikey](https://carto.com/basemaps/apikey).
   `local.properties` в `.gitignore`, ключ никогда не попадает в git.
3. Дайте Gradle синхронизироваться и запустите на устройстве/эмуляторе.

Для автосборки в GitHub Actions ключ передаётся через **Repository Secret**
(Settings → Secrets and variables → Actions → `CARTO_API_KEY`), а не через файл.

## Карта

- **OSMDroid** (OpenStreetMap), без привязки банковской карты. Обычная и цветная (Voyager)
  схемы — тайлы **CARTO Basemaps** (нужен бесплатный ключ, см. выше); спутник — Esri
  World Imagery (ключа не требует); гибрид — спутник + слой подписей CARTO поверх.
  Источники — в `util/TileSources.kt`.
- Тайлы кэшируются на диске (лимит 300 МБ) — сервер нагружается в основном при первом
  посещении новой области. Размер кэша можно посмотреть прямо на карте (мелкая подпись
  слева, только для отладки).
- Поиск адреса — через **Nominatim** (`util/NominatimGeocoder.kt`), с приоритетом по
  текущему местоположению: ищет в области вокруг пользователя нарастающего радиуса,
  чтобы не путать одноимённые улицы в разных городах/странах.
- У CARTO нет слоя с номерами домов ни в одном из бесплатных стилей — общее ограничение
  таких карт.

## Что реализовано

- **data/** — Room (Entity/DAO), репозитории, настройки на DataStore.
- **service/LocationForegroundService** — опрос геолокации, проверка геозон, уведомления.
- **ui/MainActivity** — карта, создание задач долгим тапом, поиск адреса, стили карты.
- **ui/TaskEditActivity + MapPickerActivity** — создание/редактирование задачи.
- **ui/TaskListActivity, SettingsActivity** — менеджер задач и настройки.
- **Боковое меню** — менеджер задач, настройки, консоль, «Выход» и «Закрыть совсем»
  (жёсткое завершение процесса и сервиса).
- **Консоль** (`util/AppLogger.kt`, `ui/LogActivity.kt`) — лог работы сервиса геолокации
  в реальном времени: интервал опроса, координаты, вход/выход из геозон, уведомления.
- Карта при запуске центрируется на текущей геопозиции пользователя.
- **Адаптивный алгоритм опроса** (`util/AdaptiveIntervalCalculator.kt`,
  `util/MotionState.kt`, `service/ActivityTransitionReceiver.kt`) — интервал GPS
  подстраивается под расстояние до ближайшей задачи и скорость движения (формула
  `d/(v*K)` с поправками на вид активности), с мгновенным опросом при начале движения.
  Переключается в настройках; при выключении используется ручной список интервалов.
- Изменение интервала (ручное или адаптивное) применяется сразу, без перезапуска сервиса.

## Известные упрощения

- Иконки — простые векторные заглушки.
- Esri (спутник) и Nominatim (поиск) — публичные бесплатные сервисы без гарантий SLA;
  для крупного продакшена стоит взять платного провайдера или свой инстанс.
- Адаптивный алгоритм оценивает скорость по типу активности или `location.speed`,
  без накопления дельт координат.
- На очень высокой скорости при маленьком радиусе зоны теоретически можно проскочить
  геозону между опросами — осознанный компромисс ради экономии батареи.
